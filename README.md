# claude-skills-keys

قائمة مهارات Claude المثبّتة، تقرؤها إضافة كروم **«مفاتيح مهاراتي»** وتتحدّث منها تلقائياً.

- الملف: `skills.json`
- الرابط الذي تقرؤه الإضافة:
  `https://raw.githubusercontent.com/animax940/claude-skills-keys/main/skills.json`

لإضافة مهارة جديدة: أضِف عنصراً إلى مصفوفة `skills` بالحقول `id` و`name` و`ar` و`desc` و`group` و`source` و`url`.
